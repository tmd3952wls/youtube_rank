# 랭킹형 쇼츠 렌더러 (TOP N 모음집)

클립 N개와 `plan.json` 하나로 1080x1920 랭킹 쇼츠를 만듭니다.

```
위 검정 띠: (질문 한 줄) + 분홍→보라 주제 + "랭킹 TOP7"
가운데: 세로로 긴 영상 (348~1696px, 꽉 채움)  /  아래 검정 띠
왼쪽 반투명 순위표 (새 라벨이 흐릿→선명하게 나타나고, 이전 라벨은 남음)
한 줄 리액션 자막  →  순위 사이 짧은 검은 화면 + '휙'(정점) + 다음 영상 시작에 '쿵'
```
예전 흐린 배경 템플릿은 plan.json 에 `"template": "blur"`.

## 효과음
- 효과음 폴더: `C:/Users/tmd39/Desktop/효과음/효과음600개` (`"sfx_dir"` 로 변경 가능)
- **순위 전환**은 자동: 검은 화면 한가운데에 '휙'(190_훅 / 009_쉭 번갈아), 다음 영상이 뜨는 순간 '쿵'(007_쿵).
  레퍼런스를 earshot 으로 분석해서 정한 방식 (컷마다 저음 '쿵', 시작과 몇몇 컷에 '휙').
  바꾸려면 `"transition": {"whoosh": ["..."], "whoosh_vol": 0.9, "hit": "...", "hit_vol": 0.5}`
- **장면 중간 효과음**은 클립마다 `fx`:
  ```json
  "fx": [{"at": 0.75, "sfx": "026_뜨헉!"},
         {"at": 0.0, "sfx": "175_보글보글", "vol": 0.4, "dur": 6.0},
         {"at": 3.9, "sfx": "068_군중환호", "vol": 0.6, "dur": 3.1}]
  ```
  - `sfx`: 파일 이름 일부 ("뜨헉", "026_뜨헉!" 둘 다 됨)
  - `vol`: 크기 배율 (효과음은 정점이 -9dBFS 로 맞춰진 뒤 곱함), `dur`: 길면 잘라서 끝을 줄임
  - `"peak": true`: 소리의 가장 큰 순간을 `at` 에 맞춤 (기본은 소리 시작을 `at` 에)
- 원본 소리가 없는 클립, 조용한 구간은 분위기 소리(물소리·심장박동 등)를 깔아 2초 넘게 비지 않게.
- **장면별 배경음** `"bgm": {"sfx": "233_Vlog", "vol": 0.5, "from": 20}`: 그 클립 시작부터 다음 클립 시작까지.
  평균 크기 기준으로 맞춰서 잔잔한 곡도 묻히지 않음. 같은 곡이 이어지면 끊김 없이 이어짐.
  효과음 폴더 안 배경음: 233 Vlog(신남) · 409 여행(빠른 비트) · 288 행복 · 408 카페(로파이) · 410 슬픔 · 531 살짝 긴장감 · 011 축복(합창)

## 편집 규칙 (레퍼런스 "민첩한 하루 되세요 3" 분해 결과)
- **컷은 사건이 터지는 순간 끝낸다 (제일 중요).** 풍덩·뒤집힘·펀치라인 자막이 뜨는 그 순간 + 0.2~0.4초에 `end`.
  물에서 나오기, 헤엄치기, 반응 같은 뒷이야기는 0초. "1~2초 뒷이야기가 나오면 지루하다." 앞부분 빌드업도 1~2초만.
  펀치라인 자막과 sting 은 사건 순간에 맞춘다
- **하이라이트 브금:** 제일 멋진 순간에 배경음을 확 내리고 다른 곡을 크게.
  레퍼런스 2등(배트 캐치): 배경음 -18 LUFS → 캐치 순간 묵직한 힙합 비트 -8 LUFS, 1.3초 뒤 컷
  ```json
  "sting": {"at": 4.0, "sfx": "206_히어로", "from": 30.0, "dur": 1.7, "vol": 1.4, "duck": 0.12}
  ```
  `duck` = 그동안 배경음 배율, `orig_duck` = 원본 소리 배율(기본 0.55). 후보: 206 히어로, 285 드래곤볼 웅장한 등장
- **자막 색:** 포인트 단어만 `[y:노랑]` `[r:빨강]` (그 외 `[g:]` `[b:]` `[o:]`). 예: `"([y:천운] ON.)"`, `"[r:으아악!!]"`
- **자막 애니메이션:** `"anim"`: `drop`(상황 설명, 위에서 툭) · `pop`(기본, 튀어나옴) · `shake`(비명·놀람) · `zoom`(펀치라인 쾅) · `none`
- **고화질:** `find_cc.py get` 은 4K 까지 최고 화질로 받음 (`--hq` 로 기존 클립 다시 받기). 확대가 필요하면 자동으로 선명하게 하고,
  1.6배 넘게 키우면 렌더 때 ⚠ 경고. 인코딩은 x264 slow / CRF 16

## 중요한 장면이 화면에 나오게 (2026-11-12)
가로 영상은 세로 화면에 맞추면 좌우 절반 넘게 잘립니다. 그래서:
- **자동 추적 (기본):** 클립마다 움직임이 몰린 곳을 따라 화면이 좌우로 천천히 이동합니다. 따로 적을 필요 없음
- **수동 키프레임:** 자동이 틀리면 `"focus": [[초, 가로위치], ...]` (원본 기준 0=왼쪽, 1=오른쪽, 주인공 중심 위치).
  카메라가 같이 움직이는 영상(블랙박스·헬멧캠)은 자동이 헷갈리기 쉬워서 수동이 확실함
- **덜 자르기:** `"box_h": 1100` 처럼 줄이면 더 넓게 보임
- **슬로모션:** `"slow": [시작, 끝, 배율]` (클립 안 원본 초). 예: 떨어지는 장면 0.9~2.1초를 2.5배 느리게 → `[0.9, 2.1, 2.5]`.
  자막·효과음 `at` 은 늘어난 뒤 시간 기준
- 렌더 후 각 클립의 결정적 순간 프레임을 꼭 확인

## 화면 다듬기
- `"crop": [x, y, w, h]`: 원본을 먼저 자름 (세로 영상 양옆 검은 띠 등). 0~1 비율
- `"blur": [[x, y, w, h], ...]`: 원본에 박힌 영어 자막·워터마크를 흐리게 (원본 기준 0~1 비율). 그 근처에 한국어 자막을 올리면 됨.
  소재는 **영어 자막 없는 것을 먼저**, 없을 때만 자막 있는 걸 블러해서 사용
- 제목: 주아체. 주제는 노랑(`[ ]` 로 감싸면 그 부분만 노랑, 나머지 흰색), "랭킹 TOP N" 은 빨강
  (`"title_color"`, `"subtitle_color"` 로 변경)

## 제일 중요한 규칙: 클립 순서
- **첫 클립(7등) = 후킹.** 엄청 자극적인 영상이어야 하고, 1~2초 안에 터져야 함 → `start` 를 터지기 직전으로

## plan.json
```json
{
  "title": "고양이가 고양이 한 순간",
  "sfx": {"path": "../rank_short/assets/sfx/whoosh.wav", "volume": 0.25},
  "items": [
    {"rank": 7, "label": "기습", "src": "raw/c00.webm", "start": 5.6, "end": 9.8,
     "subs": [{"at": 0.1, "dur": 1.1, "text": "(평화로운 오후)"},
              {"at": 1.3, "dur": 1.6, "text": "으아악!!"}]}
  ]
}
```
- `items` 는 **재생 순서**대로 (보통 7등 → 1등). `rank` 는 1~N 이 한 번씩.
- `start`/`end`: 원본에서 쓸 구간(초). 클립당 4~7초, 전체 36~42초.
- `subs`: **한 줄, 2~3어절.** 길면 렌더할 때 경고가 뜹니다. `at` = 클립 안에서 뜨는 초.
- 원본 소리는 그대로 나옵니다. 클립별 크기는 `"volume": 1.5` 처럼 조절.
- 클립별 화면 조정 (주인공이 잘리거나 왼쪽 순위표에 가릴 때):
  - `"focus_x"`, `"focus_y"` (0~1): 어느 쪽을 남기고 자를지 (기본 0.5 = 가운데)
  - `"box_h": 900`: 이 클립만 영상 높이 지정 (작을수록 가로 영상이 덜 잘림)
  - `"flip": true`: 좌우반전
- `sfx`(순위 시작마다 효과음, 원본 소리를 덮지 않게 작게), `bgm` 은 없어도 됩니다.
- 클립 개수만큼 자동으로 `랭킹 TOP{N}`. 바꾸려면 `"subtitle": "..."`.

## 자동 효과음 디렉터 파이프라인 확장 (Antigravity `agy` + Gemini 멀티모달)

기존 `make_rank.py` 구조를 그대로 유지하면서, AI가 초안 영상을 직접 시청하고 효과음을 자동 연출·수급·덕킹 합성하는 `rank_short/sfx_director/` 모듈이 추가되었습니다.

### 주요 기능
1. **로컬 효과음 증분 카탈로그화 (`catalog.py`)**: `LOCAL_SFX_DIR` 폴더의 오디오를 FFmpeg/NumPy 파형 분석(길이·5ms 타격 정점·dBFS) + Gemini 멀티모달 청취로 분석해 `sfx_catalog.json`에 캐싱 (신규 추가 파일만 증분 분석).
2. **영상 시청 기반 자동 큐시트 (`cue_sheet.py`)**: `joined.mp4` 초안 영상을 시청해 초반 3초 후킹, 순위 전환, 자막 애니메이션(`drop`/`pop`/`shake`/`zoom`), 슬로모션·반전 포인트를 `sfx_cue_sheet.json`으로 출력.
3. **하이브리드 매칭 & Fallback 수급 (`matcher_fallback.py`)**: 1순위 로컬 카탈로그 → 2순위 Freesound APIv2 자동 다운로드 → 3순위 ElevenLabs Sound Effects API 생성 후 로컬 폴더·카탈로그에 자동 편입.
4. **음성 보호 덕킹 & 피크 정렬 믹싱 (`mixer.py`)**: 대사/나레이션 활성 구간 대비 효과음 볼륨을 `-12dB ~ -18dB`로 자동 감쇠하고 타격 정점(`peak_time_sec`)을 타임스탬프에 맞춰 2-pass `loudnorm`(-14 LUFS) 합성.

## 암전·자막 확장 (2026-11-16, 레퍼런스 8편 공식)

- 자막 `"anim": "typewriter"` (dur 의 75% 동안 한 글자씩), `"box": false` (외곽선 글자만), `"a|b|c"` 여러 줄은 경고 없음.
- TOP6~7 에서 장호흡 클립(9~12초) 1개·초단타 클립(2.5~3.8초) 1개는 길이 경고 없음.
